# 🚀 Agent AI — Collaborative Multi-Agent Platform

> *“Not just AI… a team of intelligence working together.”*

---
visit:https://agent-hub-xi.vercel.app/
## 🧠 Overview

**Agent AI** is a full-stack MERN application that simulates a team of specialized AI agents collaborating to solve real-world problems.
Instead of a single AI handling everything, multiple agents work together — just like a human team — to plan, execute, and refine tasks.

---

## ✨ Key Features

* 🤖 **Multi-Agent System**
  Specialized agents (Development, Research, Creative, Productivity) collaborate to complete tasks.

* 📊 **User Dashboard**
  Users can manage and view only their created agents.

* 🔍 **Smart Search & Category Filtering**
  Easily explore agents using search and categorized UI (like Play Store).

* 🧑‍💻 **Authentication System**
  Secure login and registration using MongoDB.

* ⚡ **Smooth UI/UX**
  Animated transitions, modern interface, and responsive design.

* 🧩 **Scalable Architecture**
  Clean separation of frontend, backend, models, and controllers.

## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/agent-ai.git
cd agent-ai
```

---

### 2️⃣ Setup Backend

```bash
cd backend
npm install
```

Create a `.env` file:

```
MONGO_URI=your_mongodb_connection_string
```

Run backend:

```bash
npm start
```

---

### 3️⃣ Setup Frontend

```bash
cd frontend
npm install
npm start
```

---

## 🎯 How It Works

1. User logs in / registers
2. Creates AI agents with categories
3. Agents are stored in MongoDB
4. Dashboard shows user-specific agents
5. Users explore and interact with agents
